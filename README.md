# Belajar PHP

Repositori ini berisi kumpulan latihan pemrograman PHP untuk mempelajari konsep dasar PHP, pengolahan data, function, serta Object-Oriented Programming (OOP). Setiap file berisi contoh kode atau latihan yang dapat dijalankan secara mandiri.

# Materi yang Dipelajari

1. Variabel, tipe data, string, dan operator.
2. Array biasa, array asosiatif, dan array multidimensi.
3. Percabangan menggunakan if, switch, dan match.
4. Perulangan menggunakan for, while, dan foreach.
5. Function, parameter, return value, dan named arguments.
6. Pengolahan data buku dan perhitungan denda.
7. Konsep OOP: class, object, property, method, dan constructor.
8. Inheritance serta visibility public, protected, dan private.
